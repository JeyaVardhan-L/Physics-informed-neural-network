Step 02

Add the damped oscillator and its closed form

The truth that everything will be scored against. The closed form is checked against numerical derivatives, so a mistake in it can't quietly flatter a network later.

The detail to remember: b = (v0 + delta * x0) / omega_d, which isn't zero for a mass at rest.

Step 04

Add a least-squares baseline and its noise floor

Written before any network, so the bar is set by something other than a weak opponent. Two unknown constants, ten equations, and a covariance that gives the best error to expect.

A test simulates 2,000 noisy data sets and checks that the predicted error is the average one.

Step 05

Add the network

A multilayer perceptron in float64 with a private random generator.

The test for the private generator failed at first. nn.Linear draws default weights from the global generator before they are replaced, so building a network changed every later random number. skip_init fixed it.

python -m pytest tests/test_network.py -q
