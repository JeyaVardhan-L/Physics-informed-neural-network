title: The spring short: The spring hint: the physics lede: One equation, three forces, and a closed-form answer to check everything against. ---

A mass on a spring feels two forces. The spring pulls it back towards the middle with strength proportional to how far it has moved, −k x. Friction resists the motion in proportion to speed, −c x′. Newton's second law says mass times acceleration equals the total force:

m x″ = −c x′ − k x   so   m x″ + c x′ + k x = 0

This is an ordinary differential equation, or ODE. It gives a relation between position, velocity and acceleration that holds at every instant, and leaves you to work out where the mass is. This project uses m = 1, c = 3 and k = 225.

Solving it

Guess that the solution is an exponential, x = est. Each derivative multiplies by s, so the equation becomes a quadratic, m s² + c s + k = 0. Its roots are

s = −δ ± √(δ² − ω0²),    δ = c / 2m,    ω0 = √(k / m)

Here δ = 1.5 and ω0 = 15, so the square root is of a negative number and the roots are complex. A complex exponential is a rotation, so the mass oscillates while its height decays. This is the underdamped case. The oscillation frequency is ωd = √(ω0² − δ²) = 14.92, slightly slower than ω0 because friction holds it back.

x(t) = e−δt (a cos ωdt + b sin ωdt)

The two constants come from the start. Setting t = 0 gives a = x0. Differentiating and setting t = 0 gives b = (v0 + δx0) / ωd. The damping ratio

The number ζ = c / (2√(mk)) decides the character of the motion. Below 1 it oscillates, at exactly 1 it returns as fast as possible without overshooting, above 1 it creeps back. Here ζ = 0.1. The code refuses ζ ≥ 1, because the formula above would take the square root of a negative number and return nan.

Trusting the reference

Every later claim is measured against this formula, so it is tested first. The tests compare velocity() with a numerical slope of position(), and acceleration(), which is defined from the ODE, with a numerical slope of velocity().
