Runterminal

Where to take it

Each of these is a small, real extension. Write the test first, then the code, then a paragraph for the guide.

  1. A nonlinear spring. Add a k3x³ term. The closed form is gone, so make the truth with Runge-Kutta. The least-squares shortcut no longer works, and the PINN changes by one line.
  2. Hard constraints. If the start is known, let the curve be x0 + v0t + t² N(t). The start is then exact and one thing fewer has to be learned.
  3. Adaptive collocation. Every 500 steps, move points to where the residual is largest. Try it on ω = 60.
  4. Error bars. Train an ensemble of ten PINNs on resampled dots and plot the spread. Compare it with the covariance from classical.py.
  5. A driven spring. Put a force on the right-hand side, then try to recover the force from the dots.
