== # Each y[i] depends only
The sum trick. The Jacobian of `y` with respect to `t` is diagonal, so multiplying it by a vector of ones gives the diagonal.

== # create_graph=True keeps
The second derivative of a ReLU net doesn't depend on `t` at all. Without `materialize_grads=True`, autograd returns an error for an unused input. With it, it returns the honest answer: zeros.
